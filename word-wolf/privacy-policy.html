プライバシーポリシー

ワード人狼

制定日: 2026年8月20日 / 最終更新日: 2026年8月20日

当アプリは、利用者が入力した個人情報を収集しません。 入力されたプレイヤー名や遊んだ記録は、すべて端末内にのみ保存されます。 これらを端末の外へ送る仕組みは、当アプリには実装されていません。 ただし、アプリを無料で提供するために Google AdMob による広告を表示しており、 広告配信の目的で広告識別子などが第三者（Google および広告提供事業者）によって 取得されることがあります。

1. 運営者が収集する情報

当アプリの運営者は、氏名・メールアドレス・電話番号・住所・位置情報・連絡先など、 個人を識別できる情報を一切収集しません。 会員登録やログインを求めることもありません。 当アプリには、入力内容や記録を送信・共有・書き出しする機能自体がありません。

2. 端末内にのみ保存する情報

次回も続けて遊べるようにするため、以下を端末内のストレージにのみ保存します。 これらが外部に送信されることはありません。

保存する内容 目的
プレイヤー名の組み合わせ（最大 5 組）と保存した日時 次回のプレイヤー設定で、過去のメンバーを呼び出せるようにするため
お題ごとの出題回数 一度出たお題が続けて出ないようにするため
ストアの評価をお願いした日時と回数、遊んだ回数 短い間隔で繰り返しお願いしないようにするため

プレイヤー名には、利用者が入力した実名やあだ名が含まれる場合があります。 これは同じメンバーで繰り返し遊ぶときの手間を省くためだけに保存されるもので、 運営者が読むことも、広告の配信や分析に使われることもありません。 アプリ内の「設定 > プレイヤー履歴を削除」からいつでも消去でき、 アプリをアンインストールした場合も端末から削除されます。

お題の出題回数も同様に、「設定 > お題の出題履歴をリセット」から消去できます。

3. 広告について

当アプリは、アプリを無料で提供するために Google AdMob による広告 （バナー広告・全画面広告）を表示します。 プレイヤー名や遊んだ記録が広告配信に渡されることはありません。

AdMob をはじめとする広告配信事業者は、利用者の興味に応じた広告を表示するために、 広告識別子（Android 広告 ID / iOS の IDFA）、おおよその位置情報、 端末情報、広告の表示・クリック履歴などを取得・利用する場合があります。 これらの情報は当アプリの運営者が取得・保有するものではなく、 各事業者のプライバシーポリシーにもとづいて取り扱われます。

  • Google の広告におけるデータ利用: ポリシーと規約
  • 広告のパーソナライズ設定: Google 広告設定

4. トラッキングの許可について

iOS では、「トラッキングの許可」を求めるダイアログが表示されます。 許可しない場合でも、当アプリのすべての機能をご利用いただけます （表示される広告が利用者の興味に基づかないものになります）。 許可の設定は、iOS の「設定 > プライバシーとセキュリティ > トラッキング」から変更できます。

Android では、端末の「設定 > プライバシー > 広告」から 広告 ID の削除やパーソナライズの無効化ができます。

5. アップデートの確認について

当アプリは起動時に、最新バージョンの情報を確認するため、 GitHub 上に置かれた設定ファイル（バージョン番号のみが書かれた小さなファイル）を 読み込みます。このとき、通信の性質上、接続元の IP アドレスなどが GitHub 側に記録される場合があります。

この通信で当アプリから送信される利用者の情報はありません。 プレイヤー名や遊んだ記録が送られることはなく、読み込みに失敗した場合も そのまま通常どおり遊べます。お題のデータはアプリに同梱されているため、 通信できない環境でもすべての機能をご利用いただけます。

6. ストアの評価のお願いについて

当アプリは、一定の回数遊んだあとに、OS の標準機能を通じて ストアの評価用ダイアログの表示を依頼することがあります。 このとき、当アプリからプレイヤー名や記録が渡されることはありません。 依頼するかどうかの判断は、すべて端末内で行われます。

7. 解析ツール

当アプリはアクセス解析ツールやクラッシュレポートの仕組みを組み込んでいません。 利用者の行動ログを運営者が収集・保有することはありません。

8. お子様のプライバシー

当アプリは特定の年齢層に向けたものではありませんが、 運営者が個人情報を収集することはありません。 上記のとおり広告配信事業者による情報の取得が行われるため、 お子様がご利用になる場合は、保護者の方の管理のもとでご利用ください。

9. 本ポリシーの変更

法令の変更やアプリの機能追加に伴い、本ポリシーを改定することがあります。 重要な変更がある場合は、本ページの最終更新日を更新してお知らせします。

English Summary

The developer of this app does not collect any personal information. Player names you enter (up to five saved groups) and the record of which topics have already been used are stored only in the local storage of your device. The app has no feature that sends, shares or exports this data, and it is removed when you uninstall the app. Both can also be cleared at any time from the in-app Settings screen.

The app is free and supported by Google AdMob advertising (banner and interstitial formats). Advertising providers may collect and use advertising identifiers (Android Advertising ID / iOS IDFA), coarse location, device information and ad interaction data to serve relevant ads. This data is handled by those providers under their own privacy policies, not by the developer of this app. Your player names and game records are never passed to advertising.

On iOS, a tracking permission prompt is shown; declining it does not restrict any feature of the app.

At launch the app fetches a small configuration file hosted on GitHub to check whether a newer version is available. No user information is sent in this request, and the app works normally if the request fails. All topic data is bundled with the app, so the game is fully playable offline.

The app contains no analytics or crash reporting SDKs.
