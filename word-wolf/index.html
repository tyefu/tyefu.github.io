ワード人狼

ひとりだけ違うお題を配られた「ウルフ」を、会話だけで見つけ出す

スマホ 1 台を回して遊ぶ、3〜10 人向けのパーティーゲームです。 全員に同じお題が配られたように見えて、少数派だけ違うお題を持っています。 制限時間内にそのお題について話し合い、誰が違うお題を持っているかを当てます。

遊びかた

画面 内容
プレイヤー設定 3〜10 人の名前を入力する。過去のメンバーは 5 組まで呼び出せる
ゲーム設定 ウルフの人数、トーク時間、お題のカテゴリーを選ぶ
お題確認 ひとりずつ端末を受け取り、自分のお題を確認する
トーク 設定した時間だけ、お題について話し合う
投票・結果 ウルフだと思う人を選ぶ。全員のお題と勝敗が表示される

お題

2400 問以上を 17 のカテゴリーに分けて収録しています。 「すべて」を選べば全カテゴリーから出題されます。

日常 / 恋愛 / おもしろ / 一般 / スポーツ / 難しめ / 飲食 / 職業 / 学校 / 動物 / 乗り物 / 季節・行事 / 音楽 / 旅行 / 体・健康 / お金 / ゲーム・遊び

特徴

  • お題はアプリに同梱。通信は不要で、電波の届かない場所でも遊べます
  • 一度出たお題は、そのカテゴリーを一巡するまで再登場しません。 アプリを閉じても記録は残ります
  • プレイヤー名は過去 5 組まで保存。次回は選ぶだけで始められます
  • ウルフは 1 人だけでなく、人数に応じて複数にもできます
  • 同数の場合のサドンデス（延長）に対応しています
  • 無料。アプリ内課金はありません（広告を表示します）
