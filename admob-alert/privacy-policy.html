AdMob Alert

制定日: 2026年10月4日 / 最終更新日: 2026年10月4日

AdMob Alert は、運営者本人の AdMob データだけを扱う個人用ツールです。 取得したデータは運営者本人へのメール通知にのみ使い、第三者に提供・販売することはありません。

1. 取得する情報

Google アカウントで許可を受けた範囲で、次の情報を AdMob API から読み取ります。

  • AdMob のパブリッシャー ID
  • アプリ名・広告ユニット名・広告フォーマット
  • 見積もり収益・表示回数・クリック数

2. 利用目的

取得した情報は、当日の収益が設定した金額を超えたかを判定し、 運営者本人宛ての通知メール（内訳レポート）を作成するためだけに使います。

3. 保存

取得したレポートのデータは保存しません。 Google Apps Script のスクリプト プロパティに保存するのは、 同じ日に重複して通知しないための「通知済みの日付」だけです。

4. 第三者への提供

取得した情報を第三者に提供・共有・販売することはありません。 データは Google のサービス（AdMob API、Google Apps Script、Gmail）の中でのみ処理されます。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

AdMob Alert による Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。

6. アクセス権の取り消し

AdMob Alert に与えた権限は、 Google アカウントのサードパーティ製アプリとサービス からいつでも取り消せます。

7. 本ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。

English Summary

AdMob Alert is a personal tool that reads only the operator's own AdMob reports (publisher ID, app and ad unit names, estimated earnings, impressions and clicks) through the AdMob API with read-only access. The data is used solely to send notification emails to the operator, is not stored except for the date of the last notification, and is never shared with or sold to third parties. AdMob Alert's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from your Google Account permissions. Questions: katutyefu@gmail.com
