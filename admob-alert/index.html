AdMob Alert

AdMob の収益が目標額を超えたら、自分宛てにメールで知らせる個人用ツール

AdMob Alert は、運営者が自分の AdMob アカウントの収益を確認するためだけに使う Google Apps Script のツールです。一般の方に向けて提供しているサービスではありません。

できること

  • 1 時間ごとに、当日の AdMob 見積もり収益を確認します
  • 収益が設定した金額を超えた日に、1 回だけメールで通知します
  • 通知メールには、アプリ別・広告ユニット別の収益の内訳を載せます

使用する Google の権限

権限 用途
AdMob のデータの閲覧（admob.readonly） 収益・表示回数・クリック数のレポートを読み取るため。設定の変更はしません
メールの送信（script.send_mail） 通知メールを自分宛てに送るため
外部サービスへの接続（script.external_request） AdMob API を呼び出すため
スクリプトのトリガー管理（script.scriptapp） 1 時間ごとの自動実行を設定するため
